# Domain Glossary

| Term | Meaning |
|---|---|
| Creator | Influencer/talent offering promotional services |
| Brand | Organization purchasing campaign services |
| Campaign | A brand marketing initiative |
| Offer | A versioned proposal between parties |
| Booking | Accepted offer and fulfilment commitment |
| Ledger | Immutable financial record of money movements |
| Domain Event | A fact that has occurred in a bounded context |
